# Weather App 🌤️

A simple and interactive weather application built using HTML, CSS, and JavaScript. The application allows users to search for a city and view its weather information through a clean and user-friendly interface.

## Features

- 🌍 Search weather by city
- 🌡️ Display temperature and weather conditions
- 💨 Show additional weather information
- 🔍 Simple search functionality
- 💻 Clean and user-friendly interface
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

Through this project, I practiced:

- JavaScript fundamentals
- DOM manipulation
- Event handling
- Working with APIs
- Fetching and displaying dynamic data
- Frontend development

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. Search for a city to view its weather information.
